**************************
What's New in Karabo 3.1.0
**************************

This entry summarizes the changes from ``3.0.0`` to ``HEAD`` on ``main``,
including work released in the ``3.0.x`` line and additional merge requests
queued for the ``3.1`` line as of **June 19th, 2026**. In total, this range
contains ``291`` merge requests.

Summary - Release highlights
+++++++++++++++++++++++++++++

- The GUI gained more usable day-to-day workflows, including configuration
  preview, better project search and editing, Logbook screen capture and
  fit-to-view, and clearer extension and version feedback.
- ``GuiServer`` and client communication became more flexible with websocket
  support, selectable listening ports, and more reliable shutdown and data
  forwarding behaviour.
- Device and binding APIs improved around output channels, timestamps, schema
  helpers, and ``Hash`` handling, which makes C++, Bound, and MDL integrations
  easier to build and debug.
- NDArrays and Image descriptors in the middlelayer API can specify dynamic shape dimensions
  with a 0, e.g. (3, 0).
- Reliability improved across project storage and deployment with ProjectDB
  concurrency fixes, broader CI platform coverage, and refreshed Python and
  Conan dependency stacks.
